# Velo Homebrew tap

```sh
brew install adoxcol/tap/veloctl
```

`veloctl` is the command-line downloader from [Velo](https://velo.adoxcol.com): fast, resumable, segmented downloads. Ctrl+C pauses; run the same command again to resume.

The formula is updated automatically by [Velo's release workflow](https://github.com/Adoxcol/velo).
